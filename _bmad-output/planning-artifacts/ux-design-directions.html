Recommended Approach: Adaptive Layout

Since the product serves three distinct briefing shapes, consider a composite approach where the layout adapts to the user's role:

  • Executive Scan → Direction 2 (Dashboard) — metrics-first, high-level status
  • Filtered Brief → Direction 1 (News Feed) — card-based, workstream-filtered
  • Intelligence Report → Direction 6 (Split Panel) — detail + AI enrichment

Shared foundation: Red Hat palette, consistent header/navigation, same card components, unified spacing system. Only the layout structure changes per role.
