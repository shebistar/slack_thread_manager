## Challenges

1. **Git workflow gap** — stories 2.1–2.5 committed retroactively in one batch; now fixed with on_complete hook
2. **No staging validation** — zero real-data testing; all verification mock-based unit tests only
3. **Deferred item backlog growing** — 26 total items, 5 marked must-fix still unresolved from Epic 1
4. **Async testing complexity** — fire-and-forget pattern (setImmediate drain, Promise.resolve yield) required multiple iterations
5. **Story 2.1 has no implementation artifact file** — breaks documentation chain

## Key Insights

1. **`continue` is a code smell in loop-with-phases** — the Phase 2 skip bug happened because `continue` implicitly bypassed everything after it. Use if/else + always-run pattern for multi-phase loops.
2. **null vs falsy comparison is a recurring trap** — `null === someString` always false. Explicitly handle "both absent" case first.
3. **Fire-and-forget test recipe** — `await Promise.resolve()` yield at method start + `setImmediate` drain in tests. Now documented in project-context.md.
