## Successes

1. **Pattern reuse velocity** — Story 3.3 established the processor pattern (retry-once, Zod validation, golden fixtures, per-item error isolation); Stories 3.4–3.7 executed as copy-adapt-extend with increasing speed
2. **Dual-summary architecture** — generating both technical and plain-language summaries now means Epic 5 can serve multiple personas without re-running LLM calls
3. **Testing maturity** — 123 → 223 tests; golden fixture pattern validates LLM output shape without brittleness
4. **Progressive architecture** — each story built cleanly on the last with no major refactoring needed
5. **Code review effectiveness** — 26 patches caught real issues (missing timeouts, unguarded array bounds, wrong error attribution, missing DI decorators)
6. **pgvector semantic search** — HNSW index + cosine similarity working end-to-end, proving the search architecture

## Challenges

1. **`@Inject()` decorator amnesia** — flagged in every code review from Story 3.3 onward; SWC + ESM requires explicit decorators but team kept forgetting
2. **Gemini code fence wrapping** — Gemini returns JSON in markdown fences; discovered in 3.3, re-discovered in 3.4; fix should be centralized in LlmService
3. **Node.js v20 vs v22 blocker** — local API server couldn't start (Stories 3.5–3.7); E2E validation forced through direct DB queries. **Resolved**: upgraded to Node.js v24 with tsx loader for ESM workspace package resolution
4. **No full pipeline integration test** — the complete `POST /api/admin/pipeline/run` endpoint chaining all 5 stages hasn't been exercised end-to-end
5. **IDE file reversion** — Stories 3.4 and 3.5 lost files mid-session due to IDE buffer conflicts; significant time cost
6. **Epic 1 deferred items still unresolved** — 5 must-fix items now 2 epics overdue

## Key Insights

1. **Repeated review findings = missing project convention.** The `@Inject()` issue should be a hard rule in project-context.md or enforced by lint, not caught by human review.
2. **LLM response normalization belongs in the service layer.** Code fence stripping, whitespace trimming, and JSON extraction should happen once in `LlmService.complete()`, not per-processor.
3. **Node version mismatch blocks confidence.** Pipeline code validated only by unit tests + isolated DB queries. Full chain needs a cluster smoke test.
4. **Pattern reuse is a superpower.** Invest extra time in the first implementation of a pattern — it compounds across subsequent stories.
5. **Deferred items have a shelf life.** Items older than 2 epics should be triaged: fix, formally deprioritize, or delete.
